# 💣 極秘作戦：爆弾解除プロトコル (Bomb Defusal Protocol)

> **「解除班」と「分析班（マニュアル）」の2人で協力し、迫り来る爆発を阻止せよ！**

『Keep Talking and Nobody Explodes』リスペクトの2人協力型爆弾解除ウェブゲームです。

---

## 🎮 ゲーム概要

- **解除班（Defuser）**：
  - 爆弾の画面を直接操作します。
  - タイマー、ストライク（ミス許容数）、モジュール（導線、ボタン、キーパッド、サイモン、モールス信号、パスワード、迷路）を操作できますが、**解除ルールは分かりません**。
- **分析班（Expert / Manual）**：
  - 爆弾解除指示書（極秘マニュアル）を閲覧できます。
  - 各モジュールの仕様、判定条件、早見表を検索・確認できますが、**爆弾の画面を見ることは禁止**されています。
- **作戦目標**：
  - 制限時間内に2人で対話し、全てのモジュールを解除すること！

---

## 🕹️ プレイモード

1. **1人練習モード（Solo Mode）**
   - 画面上部のタブで「爆弾」「指示書」「左右同時表示」を自由に切り替えながら練習できます。
2. **2人協力プレイ（Multiplayer Mode）**
   - ルームIDを作成し、招待リンク（`?room=XXXX&role=manual`）を共有することで、2台のPCやスマホ、または別タブ間でリアルタイム同期プレイが可能です。

---

## 🧩 搭載モジュール一覧

1. **導線モジュール (Wires)**: 3〜6本の導線からルールに従って正しい1本を切断
2. **ビッグボタン (The Button)**: ラベルや色、インジケーターから短押し／長押し判定＆タイマー数値でのリリース
3. **古代文字キーパッド (Keypad)**: 4つの記号を含む列を特定し、正しい出現順にプッシュ
4. **カラーシーケンス・サイモン (Simon Says)**: 母音の有無や現在のミス数に応じたカラー変換マッピング
5. **モールス信号 (Morse Code)**: 点滅信号から英単語を解読し、対応する周波数を送信
6. **パスワード (Password)**: 5文字のダイヤルから唯一成立する単語を絞り込み特定
7. **迷路 (Maze)**: 2つの緑の円から迷路を特定し、不可視の壁を避けてゴールへ誘導

## 🚀 起動方法

### 開発・起動
```bash
# 依存関係インストール
npm install

# サーバー起動 (ポート 3000)
npm run dev
```

ブラウザで `http://localhost:3000` を開いてプレイしてください。
Codespaces上ではポート 3000 が自動でフォワードされ、プレビューまたはブラウザタブからアクセスできます。
